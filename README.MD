# 📊 Sum of Numbers Between Two Values — Mini Project

This is a simple and interactive mini project that calculates the sum of numbers between two user-defined values. It focuses on practicing core JavaScript concepts such as loops, input validation, and DOM manipulation in a clean UI.

---

## ✨ Features

- Accepts two numeric inputs from the user
- Validates that both inputs are filled and the first number is smaller than the second
- Displays error messages with red borders and a shake animation for empty or invalid inputs
- Uses a `while` loop to calculate the sum of all numbers in the given range
- Shows the result in a formatted and readable way
- The "Calculate" button is disabled until both inputs are filled

---

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- [Lalezar Font](https://fonts.google.com/specimen/Lalezar) from Google Fonts for Persian typography

---

## 🚀 How to Run

1. Clone or download the repository.
2. Open the `index.html` (or `code.html`) file in your browser.
3. Enter two numbers.
4. Click the "Calculate" button to see the result.

---

## 🧠 Educational Highlights

- Using the `while` loop for numerical range logic
- Input validation and UX feedback with CSS animations
- Real-time button activation based on input status
- Semantic HTML and modular CSS for clarity and maintainability
